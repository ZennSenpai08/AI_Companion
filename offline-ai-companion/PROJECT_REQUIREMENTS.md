# Mika — project requirements

Status: IN PROGRESS. Original Windows 10/11 x64 desktop companion, not a web service.

The accepted specification is the user's Master Development Prompt and parent AGENTS.md.
Core requirements: transparent draggable Live2D overlay, tray recovery, secure supervised
Python backend, local streaming LLM, protected original Mika persona, English/Filipino/Taglish
push-to-talk conversation, local STT/TTS, interruption, audio-driven animation, and
inspectable/editable/exportable/deletable SQLite memory. Runtime networking is loopback
only; no hosted inference fallback or account. Microphone requires explicit consent.

Phases must pass executed acceptance checks before being marked COMPLETED. No downloaded
weights, private recordings, personal databases, proprietary Core binaries or unreviewed
avatar packages belong in Git. Optional Hindsight/OpenViking/OpenJarvis stay off the core path.
No voice cloning without sufficient rights. No external publishing is authorized.

Release requires measured offline spoken conversations in all three language modes,
persona evaluation over 50+ turns, microphone and monitor recovery, cancellation,
installer verification and redistribution license review. Code presence is not evidence.
